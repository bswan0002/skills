---
name: qq
description: Answer questions without making changes. Use when the user asks for an explanation or clarification rather than implementation.
---

Answer the user's question directly and concisely. Inspect relevant context using read-only operations as needed.

Do not change files or external state, install anything, or run commands that may write artifacts. Treat a question as a request for an answer, not permission to implement a fix.

If a change would help, describe it and leave implementation to a separate request.
